Privacy Policy

This policy explains how Wanwu Facts Publisher accesses, uses, stores and deletes information when it uses YouTube API Services.

Wanwu Facts Publisher is a private, single-owner internal tool. It is not available for public registration and does not operate on behalf of unrelated YouTube users.

1. Operator and scope

Wanwu Facts Publisher is operated by an independent developer and sole proprietor for the Wanwu Facts educational channel. Questions or privacy complaints can be submitted through the public support form. Do not include passwords, OAuth codes, access tokens or other secrets in a public issue.

2. Use of YouTube API Services

The client uses YouTube API Services and is subject to the YouTube Terms of Service. Google's handling of information is described in the Google Privacy Policy.

3. Information accessed

The client accesses only the information necessary to:

  • confirm the authenticated owner controls the configured channel;
  • upload original video, thumbnail and metadata selected by the owner;
  • set the owner-selected visibility and, when selected, publication time;
  • check upload and processing status; and
  • prevent duplicate uploads and resume interrupted uploads.

This may include the channel ID and basic channel metadata, video IDs, upload-session information, processing status, owner-created titles, descriptions, tags, thumbnails, video files and schedules.

4. OAuth permissions

The client requests only these two Google OAuth scopes:

  • youtube.upload to upload owner-approved videos; and
  • youtube.readonly to verify the authenticated channel identity and processing status.

The client never requests, collects or stores the owner's Google or YouTube password. OAuth tokens are stored as GitHub Actions Secrets and are never committed to source control or displayed in logs.

5. How information is used and shared

Authorized data is used only for channel verification, video upload, processing confirmation, retry safety and publication records. It is not sold, used for advertising, used to profile viewers or shared with unrelated third parties. GitHub Actions and Google/YouTube process data only as infrastructure providers needed to run the client.

6. Storage and retention

  • OAuth refresh tokens are retained only while the owner keeps the authorization active.
  • YouTube API response data in workflow state is automatically deleted no later than 30 days after completion.
  • Build and audit artifacts expire after no more than 14 days.
  • Interrupted upload-session information is retained only to resume or safely terminate the pending upload.
  • Non-API editorial source material and original production files may be retained separately as the operator's own content.

7. Cookies and analytics

This static documentation site does not intentionally set cookies, operate analytics or serve advertising. GitHub Pages may process routine service logs under GitHub's Privacy Statement.

8. Revoking access

The owner can revoke the client's access at any time from Google Account security settings. Revocation prevents future API access. The automated workflow will fail closed if the authorization is missing or invalid.

9. Deletion requests

A request to delete data stored by the client can be submitted using the process on the Data Deletion page. Verified requests will be completed as soon as practical and within seven calendar days. Deleting client-held records does not delete content stored by YouTube; YouTube content must be removed through YouTube or another authorized client that supports deletion.

10. Security

The operator uses least-privilege OAuth scopes, repository access controls, GitHub Actions Secrets, channel-ID verification, audit logs, short artifact retention and fail-closed production switches. No method can eliminate all risk, but access is limited to what this single-owner publishing use case requires.

11. Changes

Material changes to API use, data access or retention will be reflected on this page before the changed use is deployed. If the use case changes materially, the operator will seek any review required by YouTube API Services policies.
