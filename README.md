# Wanwu Facts Publisher · API Compliance

Public compliance documentation for a single-owner internal application using YouTube Data API v3.

Live site: https://izeowz-coder.github.io/wanwufacts-api-compliance/

The site documents:

- purpose and access boundaries;
- OAuth scopes and YouTube API operations;
- owner-controlled video visibility;
- data retention and deletion;
- privacy policy and terms of use; and
- evidence for the YouTube API Services compliance audit.

No credentials, tokens, private source code or personal contact details belong in this repository.
