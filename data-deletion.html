Owner control

Revoke Access and Request Data Deletion

The authorized channel owner can stop future access immediately and can request deletion of data stored by this client.

Step 1 · Revoke Google access

Visit Google Account security settings, locate the authorization for Wanwu Facts Publisher and remove access. This invalidates future API access. The publishing workflow will stop because it cannot refresh the token.

Step 2 · Request deletion of client-held data

Open a data deletion request with the title “Data deletion request”. State only that you control the configured channel and want client-held API records deleted. Do not include passwords, OAuth codes, access tokens, refresh tokens or other secrets.

Step 3 · Verification and completion

The operator may request a non-secret ownership confirmation. Once verified, stored YouTube API response data and active OAuth secrets will be deleted as soon as practical and within seven calendar days. A completion notice will be posted to the request.

Deleting data stored by Wanwu Facts Publisher does not delete videos or other information stored by YouTube. To delete YouTube-hosted content, use YouTube Studio or another authorized client that supports deletion.

Automatic deletion

Even without a request, completed YouTube API response data is automatically removed from workflow state no later than 30 days after completion. Build and audit artifacts expire after no more than 14 days.
