A narrow publishing tool with explicit owner control.

Wanwu Facts Publisher is a private, single-owner automation client for producing and scheduling original educational videos on one channel. It is not offered to the public, does not sell access, and does not operate on third-party channels.

Single authorized owner YouTube Data API v3 Two minimum OAuth scopes 30-day API data limit No analytics or advertising
01 · Purpose

One job, one channel, one owner.

The client turns already verified source material into original Mandarin educational videos, performs automated safety and evidence checks, then uploads only to the owner-controlled Wanwu Facts channel.

Original production

Scripts, narration, subtitles, graphics, thumbnails and rendered video files are created by the operator's own workflow. Source references are preserved in the video description.

No public accounts

There is no public sign-up, no customer dashboard and no multi-tenant access. The only OAuth user is the channel owner.

No engagement automation

The client does not automate views, likes, comments, subscriptions, recommendations or audience profiling.

02 · Owner controls

Publishing remains disabled until every gate passes.

OAuth success alone cannot enable production uploads. The owner must separately confirm API audit approval and explicitly turn on the schedule.

Visibility choice

The owner can select one of three modes before upload:

  • Scheduled public
  • Private
  • Unlisted

Content review trail

Title, description, tags, source evidence, safety audit, visibility and schedule are written to a downloadable manifest before upload.

Fail-closed switches

Production requires both an API-audit approval flag and a separate automation flag. Missing credentials, scope mismatch or channel mismatch stops the run.

03 · Data flow

A short, inspectable path to publication.

Step 1 Owner consent

Google OAuth grants upload and channel-read access.

Step 2 Local production

Script, narration, graphics and video are generated.

Step 3 Safety audit

Sources, claims, media integrity and metadata are checked.

Step 4 Identity lock

The authorized channel ID must exactly match the configured ID.

Step 5 Upload and verify

Video is uploaded, processed, recorded and later pruned.

04 · API use

Minimum scopes and limited retention.

The client requests only the permissions required to verify the channel and upload owner-approved videos.

Operation Purpose Stored data Retention
channels.list Confirm the authenticated owner controls the configured channel. Channel ID match result. Only as needed for the run; API response data no longer than 30 days.
videos.insert Upload an original video with title, description, tags and visibility. Video ID, upload result and schedule. No longer than 30 days in workflow state.
thumbnails.set Attach the original thumbnail created for the video. Success or failure only. No longer than 30 days.
videos.list Confirm processing succeeds before closing the run. Temporary processing status. No longer than 30 days; artifacts expire after 14 days.
